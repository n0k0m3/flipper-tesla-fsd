BLE Board Flasher

Flash the BLE Scroll Ack firmware over USB and read the BLE passkey, or update a board over Bluetooth. BLE control only, no Wi-Fi. One bus: Vehicle CAN.

Early firmware. The NanoH2 build passed the full validation in the car. On the other boards only the USB flash and the pairing ran, on the bench. The Bluetooth update of this page worked from Chrome on a computer. From an iPhone (Bluefy) it needs firmware 0.4.2 or newer on the board, and that path is not tested on a board yet. Android is not tested. Flash on the bench, not in the car. After an erase, the board starts with Scroll Ack off and in Listen-Only.
This browser has no Web Serial, so it cannot flash over USB. Use Chrome or Edge on a computer for USB. The Bluetooth update works in this browser.
This browser has no Web Serial and no Web Bluetooth. Use Chrome or Edge on a computer, Chrome on Android, or Bluefy on an iPhone.
